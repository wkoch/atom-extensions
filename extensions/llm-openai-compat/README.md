# atom/llm-openai-compat

LLM via API compatível com OpenAI (OpenAI, OpenRouter, Ollama, LM Studio)

## Capabilities

- `net (HTTPS, base_url configurável)` — advisory [C-UI-1]: o core não bloqueia; a tela de aprovação diz isso.
- `secret:<api_key_from>` — advisory [C-UI-1]: o core não bloqueia; a tela de aprovação diz isso.

A lista normativa está em `atom.toml` (`capabilities`).
